# 화면 계약

동적 디자인: 브랜드 퍼플·코랄 행동색·노랑 강조색을 사용한다. 첫 화면 진입·스크롤 등장·버튼 및 카드 hover를 제공하고, 파티클은 회원가입 성공 시에만 생성한다. 일반 클릭에는 파티클이 없다. 800ms 후 제거하며 모션 줄이기 설정에서는 생성하지 않는다. 모션은 기능 처리와 독립적이며 모달 입력과 검색 흐름을 방해하지 않는다. 세부 토큰과 규칙은 docs/design-system.md를 따른다.

홈의 여행 탐색으로 이동해 지역·유형·검색어를 선택한다. 기본은 전체 지역·전체 유형이며 검색어는 제목·주소의 공백 구분 키워드를 모두 만족해야 한다. 필터 초기화는 기본 조건으로 재조회한다.

검색 상태는 loading → success 또는 empty 또는 error다. 새 요청이 시작되면 이전 요청을 취소하고 늦은 응답을 무시한다. 결과는 카드이며 텍스트를 HTML escape한다. 이미지 로드 실패는 기본 일러스트를 유지한다. 모드를 목록 위에 표시한다.

회원가입·로그인·내 정보·재설정은 접근성 이름이 있는 native dialog로 표시한다. Escape와 닫기 버튼으로 종료한다. HTML 입력 유효성 검사 및 서비스 오류를 제공하고 처리 중 제출을 막는다. 가입 성공 후 복구 코드를 표시하며 회원가입이 자동 로그인은 아니다.

최소 화면 폭 360px에서 검색 폼과 카드가 한 열로 배치된다. 768px·1440px에서도 화면 가로 넘침 없이 동작한다. 키보드 초점 테두리, status live region, label 연결과 reduced motion 대응을 제공한다.
