# MAP-22 지도 범위 조회

지도와 목록의 데이터·요청·취소 상태를 분리한다. 목록은 기존20건 페이지, 지도는 선택 시도와 화면 범위·유형·분류·검색어 기준이다. 지도를 이동/확대 후350ms에 자동 조회하며 이전 요청과 늦은 응답을 무시한다. 지도 이동은 목록 페이지를 바꾸지 않는다.

Given 지도 진입/범위 변경, When 조회, Then 위치기반 locationBasedList2를 사용해 현재 범위를 덮는 반경20km 이하 원들을 조회하고 직사각형 밖 결과와 중복을 제거한다. 지도는 클러스터로 표시한다. Given20개 이상, Then 목록 페이지 크기와 무관하게 조회된 장소를 모두 표시한다.

Given 넓은 범위, Then 최대16개 원을 초과하면 확대 안내를 표시한다. 한 요청 최대40회 외부 호출(회당100건), 서버15초 제한을 유지한다. 호출 상한 도달 시 partial=true와 확대 안내, 외부 실패는 오류로 표시한다. partial을 전체 조회로 표시하지 않는다. API 반경 상한은 제공 매뉴얼v4.4의 위치기반 관광정보 조회(20000m)를 따른다.

GET /api/tour/viewport: area,type,large,middle,small,west,east,south,north. 유한 WGS84 좌표와 west<east,south<north를 서버에서 검증한다. 응답 `{places,partial,zoomRequired}`. 좌표·검색어·전체 응답은 로그/저장하지 않는다. 지도 범위 내 조회라도 기존2013 시도 경계와 맞지 않는 점은 지도 집계에서 제외될 수 있음을 유지한다.
