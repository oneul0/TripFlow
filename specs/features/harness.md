# HAR-001 개발 검증 하네스

사용자 요청으로 추가한 개발 안전 경계다. 과제 요구사항 ID와 구분한다.

- HAR-001: 기본 실행과 빌드는 샘플 모드이며 키 존재만으로 실연동하지 않는다.
- HAR-002: sample/harness 빌드에는 외부 API 설정을 주입하지 않는다. live 모드만 지정한 공개 설정을 주입한다.
- HAR-003: 테스트의 기본 fetch는 실패해야 한다. 외부 응답은 명시적 대체 함수로 제공한다.
- HAR-004: E2E는 별도 포트와 새 브라우저 컨텍스트를 사용하고 외부 요청을 차단한다. 기존 개발 서버를 재사용하지 않는다.
- HAR-005: 로그는 허용된 이벤트와 개수·모드만 전달하며 이메일·좌표·비밀번호·키·검색어는 제외한다.
- HAR-006: env 변형 파일과 브라우저 검증 산출물은 버전 관리에서 제외한다.

수용 기준: 키를 설정한 환경에서도 기본 모드는 sample; live 키 누락 시 서버 조회에서 명확한 오류; fetch 실호출 테스트는 실패; 일반 회원·검색 테스트와 샘플 빌드·E2E는 통과한다. 이 하네스는 운영 인증이나 전체 비밀 탐지 시스템을 대체하지 않는다.
