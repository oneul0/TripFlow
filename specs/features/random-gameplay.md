# RND-13 수직 보드와 조작 보정

기존 RND-11 지면 투영을 사용자 요청에 따라 정면의 수직 지도 보드로 대체한다. Three.js 렌더러와 cannon-es 강체/스핀은 재사용한다.

- RND-13: Given 지도/공 / When 진입·던지기 / Then 지도는 세워진 정면 보드, 공은 화면 앞에서 깊이 방향으로 접근하며 작아진다. 판정과 화면은 같은 투영을 사용한다.
- RND-14: Given 느리거나 빠른 같은 길이의 위쪽 쓸기 / When 놓기 / Then 이동 거리 기반 유사한 목표, 정지/아래 쓸기는 취소. 속도 폭주로 보드 밖으로 이탈하지 않는다. 스핀 커브는 유지하되 제한한다.
- RND-15: Given 드래그 또는 버튼 조절 / When 조준 / Then 예상 착지점·예상 경로·목표 지역명을 표시하지 않는다(사용자 후속 요청). 발사 이후 실제 이동 궤적과 명중 결과만 표시한다. 가까운 육지 보정은 명시하고 실제 지리 경계 판정은 유지한다. 먼 바다는 실패로 안내한다.
- RND-16: Given 명중/중복/실패 / When 비행 완료 / Then 지역 강조·명중 효과·상태 문구를 표시하고 재시도 가능. 모션 감소 시 즉시 판정하며 효과 애니메이션은 끈다.

전국/시군구/읍면동, 후보 보존, 확대, 조작 잠금, 비행 취소, 360/768/1440px와 키보드 조작 유지. 보정은 보드 좌표 90 단위 이내 가장 가까운 유효한 육지 샘플로만 이동하며 UI에 안내한다. 카메라·물리 단위 테스트와 기존 브라우저 흐름 및 전체 harness로 검증한다.

## RND-17 공 집기
Given 공을 누른 상태 / When 마우스·터치를 이동 / Then 처음 잡은 오프셋을 유지해 공이 포인터를 따라 움직인다. 스핀 회전과 감소 모션 설정을 유지하며 예상 착지점·경로는 표시하지 않는다.
Given 들고 있는 공 / When 유효한 위쪽 제스처로 놓기 / Then 놓은 위치에서 비행을 시작한다(시작점으로 순간 이동하지 않음). 기존 거리 기반 목표와 보정은 유지한다. 정지·취소는 홈 위치로 복귀하고 후보를 추가하지 않는다. 포인터 캡처로 공 바깥에서도 잡기를 유지한다.

## RND-18 비행 원근감
Given 들고 있는 공 / When 지도 쪽으로 비행 / Then Three.js 원근 카메라에서 공의 깊이가 줄어들어 투영 크기가 연속 감소한다. 착지 직전 지름은 시작 지름의 절반 이하이며, 임의 CSS 축소가 아닌 실제 카메라 깊이를 사용한다. 앞쪽 시작 위치는 화면 안에 유지하고 잡기 역투영/클릭 영역도 같은 위치를 사용한다. 기존 목표 위치·스핀·착지점 비표시·모션 감소 유지.
