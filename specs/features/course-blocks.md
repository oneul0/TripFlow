# F104 / CB 코스 블록 편집

사용자 승인 범위: 서버 없이 프론트엔드 후보 장바구니·블록 연결·저장·공유·복사 편집. 이 명세가 이전 CRS/UX-CRS의 코스 부가정보 표시 계약을 대체한다. 기존 데이터와 계산/리뷰 서비스는 보존하지만 코스 UI의 점수·별점·조건 폼은 제거한다. 게시판 후기 기능은 유지한다.

## 계약
- 후보는 `enjoytrip.course-candidates.v1` version1에 사용자별 배열로 저장한다. source+contentId로 중복 제거, 최대100개. 관광지/음식점/숙박 등 탐색 결과를 담는다. 샘플·tourapi 출처를 유지한다. 비밀/좌표는 저장하지 않는다. 읽기 실패 시 원본 보존, 쓰기 실패 시 이전 상태와 화면 입력 유지.
- 기존 코스 저장소 version1 유지. stops는 최대30개, ID 중복은 확인 후 기존 블록으로 안내(중복 방문은 이번 범위에서 지원하지 않음). stay/cost는 null(미확인) 또는 유효한 추정값. 각 블록의 incomingMinutes/incomingCost는 이전 블록에서 오는 사용자 추정 구간이다. 첫 블록 구간은 합산하지 않는다. 순서 변경/중간 삭제로 이전 장소가 바뀌면 그 구간 추정치를 null로 되돌린다.
- 장소명/순서는 구성 요소, 이름은 자동 생성+선택 수정. 메타정보는 예상 시간·1인 예상 소비만 표시. 미확인을 0으로 처리하지 않고 알려진 합계+일부 미확인 표시. 실제 경로/요금 계산 아님. 출발지에서 첫 장소까지/마지막 귀가 비용은 포함하지 않음.
- 한 줄 연결 블록. 후보 추가/제거, 위아래 이동, 데스크톱 드래그, 변경 실행 취소. 모바일은 접이식 후보 패널과 버튼 조작. 화면 깊이 최대3 유지.
- 추천은 선택 가능한 샘플 시작 기능으로 보존, 기존 제공자 검증/취소 유지. 추천을 실행하면 초안을 만들고 후보도 담는다.
- 내 코스 저장/공유 snapshot/다른 코스 복사 시 방문 순서와 추정치 유지. 복사본 ID와 소유자 독립. 기존 익명 계획을 로그인 계정으로 자동 이전하지 않음. 로컬 샘플 공유라는 제한 명시.
- 관광 후보가 없으면 탐색 링크. 빈 코스 저장/공유 거절. 수정 취소와 계정 변경에는 확인, 새로고침에는 미저장 경고. 오류 후 입력 유지. 키보드 추가/정렬/삭제/취소 가능.

## 게시판 첨부 확장 및 검증 결과

게시판 첨부는 선택적 estimates={minutes,cost,timeComplete,costComplete}를 깊은 복사한다. minutes/cost는 알려진 값의 합계(0 이상 유한수), Complete는 누락 없는 합계 여부다. 기존 첨부에는 필드가 없어도 유효하다. 새 블록은 sample/tourapi 출처와 contentId를 유지한다. legacy 첨부의 시간/거리 필드는 그대로 유지하며 새 사용자 추정 합계와 구분한다.

완료 검증: 2026-10-02 harness 단위·DOM107/E2E32/빌드 및 rules:check15 통과. 자동 테스트는 외부 네트워크가 차단된 합성 환경이다. 실제 API 재호출·서버 공유 검증은 수행하지 않았다. 중복 후보 안내, 후보 복원, 버튼/드래그 정렬, 실행 취소, 추정 입력, 저장 복원, 공유 복사본 독립성, 게시판 연결을 검증했다.
