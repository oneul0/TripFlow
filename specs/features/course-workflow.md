# CB-FLOW-01~04 — 하나의 코스 제작 흐름과 티켓

- CB-FLOW-01 Given 새 코스, When 진입, Then 같은 편집 화면에서 지역·유형별 관광정보를 조회하고 후보를 담거나 제거한다. 이전에 모은 후보를 재사용한다. 조회 중/빈 결과/오류 재시도/페이지 이동을 구분하며 늦은 응답과 화면 이탈 요청은 취소한다. 샘플/실데이터/부분 페이지 의미를 표시한다.
- CB-FLOW-02 Given 후보, When 코스 구성 단계, Then 기존 블록 추가·정렬·삭제·예상 시간/금액 입력을 제공한다. 앞뒤 단계 이동 시 후보·순서·입력은 유지한다. 빈 코스 생성은 거절한다. 경로 depth는 3 이하로 유지한다.
- CB-FLOW-03 Given 완성된 구성, When 코스 생성, Then 저장이 성공한 뒤 생성 결과와 티켓을 보여준다. 저장 실패 시 구성 단계와 내용을 유지한다. 다시 수정하면 티켓은 저장 완료 전 제공하지 않는다. 기존 공유·후기 연동은 생성 결과에 모은다. 기존 계획을 열면 구성부터 수정할 수 있다.
- CB-FLOW-04 Given 저장된 코스, When 티켓 다운로드, Then 제목·방문 순서·장소 유형·예상 시간/1인 금액·미확인/샘플 표시를 담은 PNG를 생성한다. 최대 30곳/긴 제목도 누락하지 않으며 높이를 늘린다. 외부 이미지/QR/실제 예약 정보는 사용하지 않는다. 인코딩 실패 시 오류와 재시도를 제공한다. 내보내기 중 중복 실행은 막는다.

## 계약과 경계
기존 tour.findPage와 코스/후보 저장 서비스를 그대로 사용한다. 검색은 기존 공급자의 페이지 검색이며 전체 키워드 검색이라고 표시하지 않는다. 파일은 브라우저 Canvas→PNG Blob으로 생성하며 서버 업로드 없음. 제목/장소는 SVG XML 이스케이프 후 렌더링하며 외부 URL/스크립트 삽입 금지. 파일명은 고정 tripflow-course-ticket.png. 데이터 버전/인증 방식 변경 없음. 합성 사용자 자동 테스트·외부 차단·360/768/1440px 및 기존 공유 흐름 회귀 확인.

## CB-TICKET-01 — 항공권 스타일
Given 생성한 코스, When 티켓 미리보기 또는 PNG 저장, Then 브랜드 헤더·방문 순서·절취선·우측 요약표로 구성한 탑승권 형태를 동일하게 제공한다. 가상의 항공편/좌석/예약번호는 만들지 않는다. 긴 이름과 최대 30곳은 줄바꿈과 높이 확장으로 보존한다. 기존 시간·금액·미확인·샘플 표시 및 저장 오류 처리는 유지한다. 360/768/1440px에서 가로 넘침 없이 표시한다. 변경은 표현 계층만 적용하며 저장 계약은 변경하지 않는다.
