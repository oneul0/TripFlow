# CB-PLACE-01 — 코스 장소 정보 함께 표시
Given 코스 편집, When 장소 포함, Then 방문 순서대로 구성 장소 요약을 표시하고 각 블록에 유형·지역·주소·카카오지도 검색 링크를 제공한다. 후보 카드와 공유 상세에도 같은 장소 정보를 제공한다.
Given 장소 추가, When 저장·공유·복사·게시판 첨부, Then 공급된 주소를 보존한다. 주소는 선택 필드 string 최대 1000자이며 미제공/기존 저장본은 유효하다. 없는 주소나 유형을 추정하지 않는다.
Given 빈 코스, When 표시, Then 요약은 장소 추가 안내를 제공한다. 긴 제목/주소·HTML 문자는 안전하게 줄바꿈하고 텍스트로 표시한다. 지도 링크는 고정 https://map.kakao.com/link/search/ 에 인코딩된 공개 장소명·주소를 사용한다. 새창 열림을 명시한다.
코스 수준의 정보는 기존 예상 시간·금액만 유지하며 장소 자체의 정보만 보강한다. 추가 API 요청·위치 권한·외부 지도 임베드·저장소 버전 변경 없음. 원래 저장 데이터에 없던 주소는 새로 담은 장소부터 제공된다.
