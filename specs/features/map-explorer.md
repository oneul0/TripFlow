# MAP 지도 기반 지역 탐색 v1

사용자의 카카오 지도 구현 요청을 구체화한 추가 요구사항이다. 기존 F101~F103 검색과 회원 기능을 유지한다. 이번 버전은 서울 25개 구 탐색이다. 전국 집계는 수집 완료 여부와 최신 경계 확보 후 후속 범위다.

## 데이터와 표현

경계: southkorea/seoul-maps의 KOSTAT 2013 단순화 GeoJSON, Apache 2.0. 기준연도를 화면에 표시하며 최신 행정경계로 주장하지 않는다. GeoJSON [경도,위도]를 Kakao LatLng(위도,경도)로 변환한다. 이름으로 지정한 TourAPI 시군구 매핑은 경계 코드와 분리한다. 지도 집계는 중복 contentId를 제거한 현재 조회 결과이며 인기도가 아니다. 좌표가 없거나 서울 경계 밖인 항목은 목록에서 유지하고 지도 집계에서 제외한다. 주소 문자열로 구를 추정하지 않는다.

## 수용 기준

- MAP-001: Given 기본 샘플 실행, When 탐색 진입, Then 외부 SDK를 요청하지 않고 서울 경계 미리보기·합성 장소·목록을 표시한다. 공개 Kakao 키를 설정하고 지도 모드를 명시적으로 켠 경우에만 Kakao SDK를 로드한다.
- MAP-002: Given 검색 완료, When 구 경계 또는 구 선택 버튼 클릭, Then 해당 구의 장소만 목록에 표시하고 경계 윤곽선과 구명·개수·선택 상태를 갱신한다. 서울 전체로 돌아가면 구 선택을 해제한다. 다른 시도 검색은 기존 목록을 유지한다.
- MAP-003: Given 같은 검색 조건, When 지역별 장소 개수가 증가, Then 로그 스케일 강도가 감소하지 않는다. 밝기는 현재 조회 결과에 한정하며 빈 구도 클릭 가능하다. 미조회 지역을 0으로 단정하지 않는다.
- MAP-004: Given 좌표가 겹친 장소, When 밀도 그리기, Then 빛을 누적하되 지역 경계 안으로 마스킹하고 투명도를 제한한다. 이동·확대·크기 변경 후 좌표를 다시 투영한다.
- MAP-005: Given 장소 마커 또는 목록의 지도 버튼 클릭, Then 같은 장소를 선택하고 상세 패널에 제목·주소를 안전하게 표시한다. 좌표 없는 장소는 지도 선택 버튼을 제공하지 않는다.
- MAP-006: Given 지도 이동, When 지도 idle, Then 목록은 자동 변경되지 않고 범위 검색 버튼으로 확정한다. 구 선택과 필터 변경은 오래된 범위를 해제한다.
- MAP-007: Given SDK 오류·키 누락, When 지도 시작, Then 안전한 오류·재시도와 샘플 경계 미리보기를 제공하고 목록 검색은 유지한다. 오류 원문·키를 UI나 로그에 표시하지 않는다.
- MAP-008: Given 키보드/360·768·1440px/모션 감소 설정, When 탐색, Then 구 선택·전체 복귀·장소 선택이 가능하고 가로 넘침과 지속 점멸이 없다.

## 구조와 테스트

RegionExplorer는 좌표·경계 포함 판정, 집계, 선택 필터를 담당한다. BoundaryCatalog는 경계를 제공한다. MapView는 update/focus/getBounds/destroy 및 선택·이동 이벤트 계약이며 Kakao와 샘플 SVG 구현을 제공한다. UI가 SDK 객체를 다루지 않는다. Canvas는 밀도 계산 결과만 그린다. 자동 테스트는 외부 요청을 차단하고 SDK 대체 객체를 사용한다. 실 SDK 정렬·연동 확인은 키와 도메인 등록 후 별도 수행한다.
