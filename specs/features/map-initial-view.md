# MAP-INIT-01 — 지도 기본 위치와 화면 복원

Given 최초 지도 진입, When 지도 영역이 표시됨, Then 서울시청(37.5665, 126.978)을 기본 중심으로 시작하고 선택 지역 경계에 맞춘다.
Given 숨겨진 화면에서 지도 생성, When 폭/높이가 0, Then 경계 맞춤을 보류하고 화면이 표시된 뒤 적용한다.
Given 사용자가 지도 이동 또는 지역 선택, When 화면 크기 변경·다른 화면에서 복귀, Then 기존 중심을 유지하며 재배치한다. 숨겨진 동안 선택한 지역은 표시 시 적용한다.
외부 데이터·저장소 계약 변경 없음. 기본 좌표는 공개 장소이며 위치 권한을 요청하지 않는다. 해제된 지도는 크기 변경에 반응하지 않는다. 오류/재시도와 목록 대체 경로는 유지한다.
