# RND 공 던지기 여행 후보

## v2 변경 수용 기준 (2026-10-02, 사용자 수정 요청)

기존 서울 제한과 직접 작성한 적분기를 대체한다. Three.js 0.186.1(원근 카메라·구체·회전·WebGLRenderer, 미지원 시 SVGRenderer)와 cannon-es 0.20.0(강체·중력·각속도·고정 스텝)을 사용한다. 커브 힘의 계수와 입력 해석만 앱에 둔다. 접지 그림자는 지면에 별도 표현한다. 기본 샘플/하네스의 외부 차단은 유지한다.

- RND-10: Given 원형 드래그 또는 키보드 스핀 값, When 잡고 돌리거나 비행, Then 3D 공의 비대칭 표식·띠가 회전하며 공을 놓기 전에도 회전량이 보인다. 회전 감지는 위쪽 발사 여부와 독립이다.
- RND-11: Given 지면과 공, When 공이 멀어지거나 떠오름, Then 동일한 Three.js 원근 카메라로 크기·높이·접지 그림자를 투영하고, 착지 판정은 지면 좌표를 사용한다. 2D 입력은 ray/plane 역투영으로 지도와 일치시킨다.
- RND-12: Given 전국 경계, When 시도 → 시군구 → 읍면동 선택 또는 확대 탐색, Then 전국 17개 시도·251개 시군구·3482개 읍면동(KOSTAT 2013)에서 선택/착지/담기가 동작한다. 지역 전체 경로와 경계 버전을 저장하고 이전 서울 후보는 보존한다. 역사적 명칭/구역을 최신으로 오인시키지 않는다.
- RND-13: Given 담은 지역, When 관광정보 보기, Then 샘플 모드에서는 합성 목록, live에서는 한국관광공사 국문 관광정보 서비스_GW의 지역 기반 관광정보를 보여준다. KOSTAT 코드와 TourAPI 코드를 직접 혼용하지 않는다. 관광정보는 시도 단위 조회 미리보기(최대20개)임을 표시하고 읍면동 내부 결과로 단정하지 않는다. 로딩·빈 결과·오류·재시도·이전 요청 취소를 구분한다.
- RND-14: Given 명시적 map/live 모드, When 지역 관광정보 열기, Then 카카오 지도에 선택 지역 경계와 유효 관광지 좌표를 표시하고 지도 확대/축소 및 지도/스카이뷰를 지원한다. 키 누락·SDK 실패 시 안전한 안내·재시도와 목록을 유지한다. 샘플은 외부 SDK를 요청하지 않는다. 실제 키 값·정밀 좌표·API 응답을 로그에 출력하지 않는다.

전국 경계 출처는 southkorea/southkorea-maps의 KOSTAT2013 간소화 자료이며 원본 코드 접두사(시도2/시군구5/읍면동7자리)로 계층을 구성한다. 관광API 매핑은 시도만 별도 허용 목록을 사용한다. 키 존재만으로 실연동을 켜지 않는다. 실제 인증/도메인 연동과 기기 조작감은 자동 테스트와 별도 확인 사항이다.

기존 F101 실 API 미검증 상태는 유지한다. 앱과 배포 단위는 하나이며 라이브러리와 외부 API는 어댑터/지도 모듈 안에 격리한다.

## 계약과 정책
- 지역 식별자는 KOSTAT2013 코드 문자열이다. 경계는 기존 Polygon/MultiPolygon과 구멍을 보존한다. 경계선 동률은 코드 오름차순으로 결정한다.
- 공 위치는 800×600 정규화 화면의 x/y와 높이 z다. 지도의 투영·확대 역변환으로 착지점을 원본 경계에 대응시킨다. 뷰포트별 제스처는 정규화한다.
- 최근 120ms 이동 속도로 발사하고 전체 제스처의 유효 방향 변화로 스핀을 계산한다. 중력, 속도·스핀 상한, 회전 감쇠를 적용한다. 고정 1/120초 물리 스텝으로 전체 궤적을 계산한 뒤 렌더링하므로 프레임 속도가 결과에 영향을 주지 않는다. 첫 착지로 확정하며 바운스·바람·숨겨진 무작위 보정은 없다.
- 지도 위 휠/핀치는 확대, 공에서 시작한 포인터는 던지기다. 키보드 방향·세기·스핀 입력으로 같은 계산을 실행한다. 드래그 중·비행 중 지도 설정은 잠긴다.
- 비행 취소(화면 이탈/숨김/크기 변경), 입력 취소, 느린 놓기, 지도 밖 착지는 추가하지 않는다. 중복은 그대로 강조한다. 모든 지역이 담겼으면 발사를 막는다.
- 후보 저장 키 enjoytrip.random-candidates.v1, 값 {version:1,items:[{id,name,path,boundaryVersion,addedAt}]}이다. 좌표·입력 경로는 저장하거나 로그에 남기지 않는다. 읽기/형식 오류 시 원본을 덮어쓰지 않고 사용자 초기화 선택을 제공한다. 쓰기 오류 시 메모리 목록 유지 및 재시도를 제공한다. 구버전 후보는 확인 필요로 표시한다.

## Given / When / Then
- RND-01: Given 전국 경계, When 지역 선택·스크롤·핀치·확대 버튼, Then 화면 범위가 바뀌며 현재 행정 단위를 표시한다. 읍면동은 시군구를 선택한 뒤 탐색한다.
- RND-02: Given 공을 잡음, When 위로 쓸어 놓음, Then 최근 속도/방향으로 한 번 발사한다. 느린 놓기 또는 pointercancel은 복귀한다.
- RND-03: Given 반대 방향 회전 입력, When 같은 발사 속도로 놓음, Then 반대 방향 커브를 만든다. 미세 손떨림은 무시한다.
- RND-04: Given 같은 발사 조건, When 다른 렌더링 프레임 속도, Then 같은 물리 궤적과 착지점이다.
- RND-05: Given 첫 착지, When 화면 좌표 역변환·경계 판정, Then 대상 지역 하나 또는 실패를 결정한다. 구멍·경계·MultiPolygon을 처리한다.
- RND-06: Given 유효 착지, When 추가, Then 중복 없이 한 번 담고 전체 이름과 선택 테두리를 표시한다.
- RND-07: Given 실패·취소·중복·모두 담음, When 동작, Then 거짓 성공 없이 상태를 안내하고 취소된 비행은 나중에도 담지 않는다.
- RND-08: Given 후보 목록, When 삭제·실행 취소·새로고침·저장 오류, Then 목록 복원·안전한 실패/재시도가 동작한다.
- RND-09: Given 360/768/1440px·키보드·모션 감소, When 던지기와 후보 관리, Then 가로 넘침 없이 완료하고 모션 감소는 동일 계산 결과를 즉시 표시한다.
