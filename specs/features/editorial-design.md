# EDIT-01~04 — 지도·커뮤니티 디자인 개선

사용자 제공 디자인 개선안(2026-10-02)을 기준으로 한다. Eddie의 크림·보라색 공통 스타일, TUX의 Good is the New Cool 편집형 콘텐츠 위계, Netflix 지도 중심 구성을 참고한다. 참고 사이트의 자산은 복제하지 않는다.

## 수용 기준
- EDIT-01 Given 홈 진입, When 표시, Then 대형 풍경 대신 짧은 소개와 지도 탐색/최근 이야기 7:5 블록을 제공한다. 최근 글은 기존 board.list()의 최신순 최대 3개이며 제목·본문 요약·작성자·샘플 표시와 실제 상세 링크를 사용한다. 재방문하면 갱신된다.
- EDIT-02 Given 사진·추천 여부가 없는 게시글, When 목록 표시, Then 임의 사진이나 추천을 만들지 않고 제목·요약·작성자·날짜를 표시한다. 상세 읽기 폭은 760px 이하로 한다. 기존 검색·분류·작성·수정·삭제·코스 첨부는 유지한다.
- EDIT-03 Given 지도 탐색, When 데스크톱 화면, Then 400px 왼쪽 지역 패널과 오른쪽 지도를 제공한다. 작은 화면에서는 지도 다음 패널로 배치한다. 지도·목록 전환과 오류·재시도·조회 범위를 유지한다.
- EDIT-04 Given 모든 주요 화면, When 360/768/1440px 또는 키보드·모션 감소 사용, Then 가로 넘침 없이 조작 가능하고 포커스·선택 표시와 44px 주요 조작 영역을 제공한다. 공통 색상은 #F7F6F2/#6849DB, 카드 12px, 큰 블록 20px, 내용 폭 1280px 기준이다.

## 데이터와 경계
기존 게시글 계약(id,title,content,authorName,createdAt,sample)만 읽는다. 문자열은 HTML로 해석하지 않는다. 0개는 작성 안내, 읽기 실패는 안전한 안내와 재시도를 제공하며 원본 예외를 노출하지 않는다. 긴 제목은 줄바꿈한다. 샘플·부분 조회·오류를 숨기지 않는다. 기존 저장소와 API 계약, 경로 depth 최대 3은 변경하지 않는다.

이번 적용은 표현과 홈 최신 글 연결이다. 댓글·인기 정렬·사진 업로드·추천 선정·게시글 저장·관련 글 자동 연결은 데이터 계약이 없어 새로 만들지 않는다. 지도 이동 시 조회 정책은 기존 전국 탐색 요구를 보존하며 별도 행동 변경 없이 유지한다. 실제 API/지도 연결 검증은 디자인 자동 검증과 구분한다.

키보드 수용 기준: 홈 최신 글을 Enter로 열면 게시판 상단이 아닌 해당 글 제목에 포커스한다.

## 검증 결과 (2026-10-02)
단위/DOM 118개, E2E 35개, 빌드 및 rules:check 15개 통과. 360/768/1440px 가로 넘침·패널 위치·상세 키보드 포커스 확인. 샘플 홈·커뮤니티 화면 육안 확인. 실 API·카카오 SDK 연결은 이번 디자인 검증에서 실행하지 않았다.
