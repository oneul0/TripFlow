# UIA 목적별 화면 분리

- UIA-01 Given 첫 방문, When 홈 진입, Then 소개/3개 진입 카드만 표시하고 기능 화면은 숨긴다.
- UIA-02 Given 공통 메뉴, When 기능 선택, Then 선택한 화면 하나만 표시하고 aria-current·제목 초점·이동 경로를 갱신한다. 깊이는 홈1/기능2/상세3 이하이다.
- UIA-03 Given 후보가 있는 상태, When 후보함→관광정보→복귀/브라우저 뒤로, Then 별도 상세를 표시하고 후보 목록·삭제·실행 취소·저장 복원을 유지한다.
- UIA-04 Given 검색 조건과 결과, When 목록/지도 전환 또는 다른 화면 왕복, Then 조건과 결과가 유지되며 전환은 새 depth를 만들지 않는다.
- UIA-05 Given 직접 URL/새로고침, When 유효 후보 상세, Then 저장한 후보를 복원해 상세를 표시한다. 잘못된 후보는 후보함으로 이동하고 안내한다. 알 수 없는 화면은 홈으로 이동한다.
- UIA-06 Given 비행/상세 요청 진행 중, When 다른 화면 이동, Then 비행·요청을 취소하고 이전 결과가 새 화면을 덮어쓰지 않는다.
- UIA-07 Given 360/768/1440px·키보드·모션 감소, When 시나리오 수행, Then 숨긴 화면에 초점이 가지 않고 메뉴·현재 위치·뒤로 이동을 사용할 수 있다.

계획/시나리오: docs/ui-reorganization.md. 기존 RND/F/MAP/HAR 요구사항은 유지한다. 데이터 저장 형식 변경 없음. 계정 패널은 전역 계정 작업이며 패널을 중첩하지 않는다. 카카오 외부 길찾기 링크는 앱 내부 화면 계층에 포함하지 않는다.
