# RND-STYLE-01 — 랜덤여행 미니게임 디자인

Given 랜덤여행 진입, When 화면 표시, Then 보라색 아케이드 프레임 안에 지도 플레이 영역, 조작 패널, 결과 상태, 후보 개수를 명확히 구분한다. 실제 데이터 없는 점수·레벨·타이머를 만들지 않는다.
Given 공 조작, When 집기·스핀·던지기, Then 기존 물리·원근감·후보 저장 동작을 유지하고 예상 착지점을 표시하지 않는다.
Given 360/768/1440px, When 표시, Then 지도는 종횡비를 유지하고 모바일 조작 패널은 아래로 이동한다. 주요 조작 44px, 키보드 라벨·포커스, 모션 감소 지원을 유지한다.
Given 성공·실패·저장 오류, When 결과 표시, Then 기존 상태 문구가 배경과 충분한 대비로 표시되며 다른 페이지의 후보함 스타일은 변경하지 않는다.

데이터/API/저장소 계약 변경 없음. 이번 변경은 정적 안내와 시각 배치로 한정한다. 기존 RND/E2E 수용 기준과 전체 harness로 회귀 검증한다.
