# RND-SPIN-01 — 회전 관성과 잡기 피드백
Given 공을 원형으로 드래그, When 마우스를 멈춤, Then cannon-es 각속도 감쇠에 따라 공이 계속 돌다가 느려진다. 마지막 회전 방향을 유지하고 프레임 간격에 독립적으로 감쇠한다.
Given 스핀 후 던짐, When 비행 시작, Then 현재 회전 자세와 남은 각속도를 전달한다. 기존 물리 경로·후보함·예상 착지점 비표시를 유지한다.
Given 공을 잡음, When 유지, Then 잡힌 테두리와 최대 12개의 떨어지는 반짝이를 표시한다. 놓기·취소·페이지 이동·해제 시 효과와 예약 프레임을 정리한다. 모션 감소 시 정적인 잡기 테두리만 표시한다.
데이터 저장/API 계약 변경 없음. 숨겨진 화면 및 취소 후 계속 도는 애니메이션을 남기지 않는다. 버튼 스핀 조절에도 같은 감쇠 피드백을 적용한다.
