# F111 / WTH-01~05 — 코스 날짜와 관광지 예보

## 수용 기준
- WTH-01 Given 코스 편집, When 여행 날짜와 첫 방문지가 정해짐, Then 해당 날짜의 기상청 관광지 예보를 표시한다. 신규 코스 날짜는 한국시간 오늘, 기존 날짜 없는 코스는 날짜 선택 안내. 날짜 변경·첫 방문지 변경·이탈 시 이전 요청을 취소하고 늦은 응답을 무시한다.
- WTH-02 Given 장소, When 예보 지점 연결, Then 첨부 관광지 CSV의 같은 지역·정확한 이름이 유일한 경우 또는 좌표에서 5km 이내 가장 가까운 지점만 사용한다. 시도 중심을 실제 장소 날씨로 대체하지 않는다. 지점명과 주변 예보 여부를 명시한다. 연결 불가·날짜 미선택·예보 범위 밖·빈 자료·오류/재시도·로딩을 구분한다. 예보는 한국시간, 제공된 3시간 간격이며 1시간 단위로 보간하지 않는다.
- WTH-03 Given 실연동, When 요청, Then 서버 전용 WEATHER_API_KEY를 /api/weather/forecast에서만 사용한다. 고정 기상청 HTTPS URL, GET·동일 origin·허용 파라미터·지점·달력 날짜 검증, 시간 제한, 취소, 제한된 페이지 수를 적용한다. 키/상위 오류/좌표/검색어를 로그·브라우저에 노출하지 않는다. 기본 개발·빌드·테스트는 명시된 합성 예보만 사용한다.
- WTH-04 Given 유효한 응답, When 정규화, Then 조회 지점과 날짜에 해당하는 행만 정렬·중복 제거한다. 누락 값·범위 밖 온도/강수확률·알 수 없는 하늘코드는 미확인으로 유지한다. 전체 코스 날씨라고 주장하지 않으며 첫 방문지 기준임을 표시한다. 오늘~모레만 조회를 시도하고 실제 제공 시각이 없으면 자료 없음으로 처리한다.
- WTH-05 Given 생성된 코스, When 티켓 표시/PNG 다운로드, Then 날짜·첫 방문지 예보 지점·3시간별 이모지·기온·강수확률·조회시각·샘플 표시를 동일하게 포함한다. 긴 지점명과 최대 8개 시각은 줄바꿈한다. 저장 당시 예보임을 표시하며 지금 날씨로 오인시키지 않는다. 예보 오류가 코스 저장을 막지 않는다. 날짜 없는 기존 데이터·공유/복사 호환 유지. 360/768/1440px, 키보드, PNG 다운로드 검증.

## 계약
`input.tripDate?: YYYY-MM-DD`, `input.weather?: {date,stationId,stationName,nearby,status,mode,fetchedAt,slots:[{time:HH:mm,sky,temperature,pop}]}`. status=ready/empty/unavailable/error; loading은 저장하지 않는다. slots 최대8, time 유일. 저장소 버전 유지. 새 장소에 공개 관광지 latitude/longitude 선택 필드만 보존하고 현재 사용자 위치는 수집하지 않는다. 공유 revision은 여행날짜·예보 스냅샷을 함께 보존한다.

## 근거
사용자 제공 기상청27_관광코스별_관광지_상세설명서(20231130).docx 및 관광지 지점 CSV. 동네예보는 일8회, 발표시각+4시간부터 3시간 간격, 46~67시간 범위. [공공데이터포털](https://www.data.go.kr/data/15056912/openapi.do), [기상청 API허브](https://apihub.kma.go.kr/apiList.do?seqApi=971&seqApiSub=987). SKY의 기본1~4 이외 코드는 미확인 처리, 숫자 강수량 양수는 강수로 표시하며 강수확률만으로 비라고 단정하지 않는다. 실 API 인증·등록 승인 검증은 합성 테스트와 별도.
