# F104/F110 코스 추천·공유 수용 기준

상태: 운영 수용 기준 / 당일 합성 샘플 일부 구현. 아래 최신 매핑에서 구현 범위를 구분한다. F104=계획, F110=공유게시판. 아래 CRS는 사용자 추가 요청의 구체화다. [설계](../../docs/course-recommendation-design.md), [인터페이스](../course-interfaces.md)를 함께 적용한다. 자동 검증 전 통과라고 표시하지 않는다.

각 단계는 먼저 실패 테스트 실행과 실패 원인 확인 후 구현한다. 코스 기능의 테스트 파일은 아직 생성하지 않았다. 기존 harness 성공을 새 기능 통과로 간주하지 않는다. 개발 완료 시 rules:check+harness 필수, 실제 관광/길찾기/AI/다중사용자 권한 검증은 별도 기록한다.

## 2026-10-02 구현 슬라이스

첫 구현은 단계1~2의 **합성 코스 샘플**이다. 운영 서버·AI·실 경로는 활성화하지 않는다. 샘플 전용 공개 장소/가격/구간 fixture와 합성 체험 사용자(실 계정과 분리)로 계획·공유·저장·리뷰·적합도 전체 흐름을 제공한다. 날짜 미정 당일 일정으로 시작하며 다일/실제 지명 해석은 미지원으로 표시한다. 실제 검색/랜덤 지역을 가져온 경우 해당 지역 샘플이 없으면 빈 결과로 안내한다. 임의로 다른 지역을 추천하지 않는다. 로컬 저장·다중 탭 충돌은 운영 보장을 대체하지 않는다. 아래 슬라이스 검증을 완료한 뒤 서버 단계로 넘어간다.

- Given 체험 사용자가 합성 장소 조건을 선택, When 추천, Then 당일 초안을 만들고 샘플 시간·비용 표시.
- Given 내 초안, When 저장/공개, Then 개인 입력 제외 공개 스냅샷을 만들고 수정해도 기존 버전 유지.
- Given 다른 합성 작성자 공개 코스, When 저장/복사/리뷰, Then 저장 버전 고정·독립 초안·리뷰 평균과 개인 점수 분리.
- Given 확인되지 않은 정보나 조건, When 평가, Then 점수null·부족 항목을 표시.

## UX-CRS-01~04 입력 최소화

- Given 새 코스, When 진입, Then 목적 지역만 필수이며 제목·예산·취향·시간은 초기 화면에 노출하지 않는다.
- Given 미입력 취향, When 추천, Then 기본 추천으로 표시하고 개인 점수를 만들지 않는다. 과거 출처 불명 기본값도 개인 선호로 간주하지 않는다.
- Given 추천 결과, When 조건 조정/일정 편집 선택, Then 같은 depth에서 선택 입력을 제공하고 접기·이동 후 보존한다.
- Given 공개 코스, When 진입, Then 조건 폼은 접혀 있으며 같은 체험 사용자가 이번 세션에 지정한 조건을 재사용한다. 사용자 전환 시 조건은 초기화한다.
