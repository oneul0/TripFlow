# MAP-20 / TOUR-47 전국 탐색 수정

## MAP-21 자동 지도 조회

Given live 탐색 최초 진입, When 화면 생성, Then 서울을 기본 선택하고 검색 없이 첫 페이지를 지도에 표시한다. Given 지역 선택 변경, When change 발생, Then 기존 요청을 취소하고 해당 지역 첫 페이지를 자동 조회한다. 늦은 응답은 무시한다. 검색 버튼과 목록 전환은 유지한다. live 초기화는 서울로 복귀한다. 자동 조회도20건·현재 페이지 기준 안내 및 오류 상태를 유지한다. 샘플 모드의 초기 목록 보기는 유지한다.

- Given 부산·제주 등 시도 선택, When 검색, Then 제목·시군구 선택·SVG/카카오 경계와 범위는 선택 시도에 일치한다. 구역 클릭이 지역을 서울로 바꾸지 않는다.
- Given 지역 변경 중 늦은 응답/SDK 연결 완료, When 이전 작업이 끝나면, Then 최신 지도와 검색 결과를 덮어쓰지 않는다.
- Given 결과가 1000개 이상, When live 검색, Then 20개 단위 페이지와 전체 건수를 제공하며 결과량만으로 실패하지 않는다. 다음/이전 페이지를 선택할 수 있다.
- Given 검색 조건 변경, When 새 검색, Then 첫 페이지로 초기화한다. 실패하면 재검색할 수 있고 빈 결과/미확인 상태를 구분한다.
- Given 페이지별 지도 집계, Then 전체 밀도가 아닌 현재 페이지 결과임을 표시한다. 검색어는 현재 페이지 내부에서만 필터링함을 표시한다.

기존 Catalog.list는 유지한다. page(filters+pageNo)와 Tour.findPage는 `{places,totalCount,pageNo,partial,mode}`를 반환한다. pageNo는1~100000 정수,20개 고정. sample 서비스는 기존 전체 목록을 반환한다. 지도는 기존 KOSTAT2013 시군구 데이터로 확장하며 최신 경계라고 표시하지 않는다.
