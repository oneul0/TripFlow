# UX-COPY-01 사용자 화면의 개발 메모 제거
Given 랜덤 여행·게시판·코스·탐색·회원 화면 / When 사용 / Then 저장 구현 방식, 육지 보정 ON, SDK 설정, 내부 경계 ID 등의 개발 설명을 노출하지 않는다. 기능 안내·오류·재시도·샘플 표식·부분 조회·추정치 등 데이터의 의미를 전달하는 정보는 짧은 사용자 문구로 유지한다.
사용자의 명시 요청으로 로컬 저장 제한의 상시 화면 안내를 제거하고 README의 제한 설명을 유지한다. 실제 서버 공유 기능을 추가하거나 저장 계약을 변경하지 않는다. 기존 동작 테스트는 보존하고 변경한 문구의 기대값만 새 계약에 맞춘다.
