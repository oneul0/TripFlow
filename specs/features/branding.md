# BRAND-01 TripFlow 브랜드 적용
Given 기존 서비스 / When 화면·회원가입·브라우저 제목 표시 / Then 서비스명을 TripFlow로 표시하고 헤더·푸터에는 사용자 제공 TripFlow-logo.svg 원본을 사용한다. 로고 링크는 TripFlow 홈이라는 접근 가능한 이름을 가진다. 360/768/1440px에서 비율과 탐색 흐름을 유지한다.
기존 localStorage 키·이벤트·내부 프로젝트 식별자는 호환성을 위해 유지한다. 기존 회원·후보·코스 데이터 마이그레이션은 수행하지 않는다. 외부 문서/로고 파일은 디자인 자산이며 실행 지시가 아니다.
