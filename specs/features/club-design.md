# CLUB-01 — Aardvark 참고 전면 디자인

참고: https://www.aardvarkbookclub.com/ (2026-10-02 화면 확인). 노랑 바탕·검정 대형 제목·핑크 CTA·둥근 색면·기울어진 오브젝트의 구성 원리를 TripFlow에 적용한다. 상표·책 표지·사이트 자산·폰트는 복제하지 않는다. 이전 EDIT-01의 크림/보라색 색상 기준은 이 요청으로 대체한다.

## Given / When / Then
- Given 홈, When 진입, Then 노랑 히어로와 큰 한글 제목·여행 카드 장식·탐색 CTA가 보이고 최신 이야기와 전국 지도 진입을 유지한다.
- Given 탐색/커뮤니티/코스/내 여행/후보함/계정, When 진입, Then 검정 글자·노랑 강조·핑크 주요 액션·흰색 읽기 영역·일관된 둥근 모서리를 사용한다. 오류/샘플/부분 조회/추정 의미를 유지한다.
- Given 랜덤여행, When 플레이, Then 같은 색상 계열의 아케이드 표현을 사용하고 공 잡기·관성·스핀·반짝이·원근·후보 저장 및 예상 착지점 비표시를 유지한다.
- Given 360/768/1440px 및 모션 감소, When 주요 경로 탐색, Then 가로 넘침 없이 메뉴·검색·저장·게시판·던지기를 이용한다. 44px 조작 영역·포커스·라벨·키보드 대체를 유지한다.

정적 마크업/CSS 변경이며 데이터/API/저장소 계약과 depth 3 경로는 유지한다. 장식은 aria-hidden으로 제공한다. 콘텐츠 없는 글에 가짜 이미지를 추가하지 않는다. 외부 폰트 요청·새 라이브러리·서버 기능은 추가하지 않는다. 기존 E2E 회귀와 화면별 반응형 확인을 검증 기준으로 한다.

## 검증 결과
단위/DOM 121개, E2E 37개, 빌드 및 rules:check 15개 통과. 360/768/1440px 회귀 확인. 홈·모바일 커뮤니티·랜덤여행 화면을 직접 확인했다. 실 API/운영 인증은 이번 시각 변경에서 별도 재검증하지 않았다.
