# RND-ZOOM-01 — 축소 시 상위 지역 복귀
Given 확대 배율이 1보다 큼, When 축소, Then 현재 지역에서 1배까지 축소한다.
Given 최소 1배의 읍면동 지도, When 축소, Then 해당 시도의 시군구 전체로 복귀한다. Given 시도 내부 또는 전국 세부 단위, When 1배에서 축소, Then 전국 시도 지도로 복귀한다.
Given 전국 시도 1배, When 추가 축소, Then 그대로 유지한다. 버튼·휠·핀치가 동일한 축소 경로를 사용한다.
Given 공 잡기/비행 중, When 축소 입력, Then 범위는 변하지 않는다. 전국으로 버튼은 즉시 전국 복귀를 유지한다.
저장 데이터/API 계약 변경 없음. 상위 복귀 시 선택 강조와 배율을 초기화하고 실제 드롭다운·지역 단위를 동기화한다. 후보함은 변경하지 않는다.
