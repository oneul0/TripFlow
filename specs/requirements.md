# 필수 기능 명세

원문 PDF의 F101~F103, F107~F108을 구현한다. 단일 프론트엔드 앱과 단일 빌드로 배포하는 모듈형 모놀리식이다. 실제 AI·중앙 로그·전문 검색 엔진은 후속 구현이며 이번에는 교체 가능한 계약을 정의한다.

## 관광 검색 F101 F102 F103

- Given 지역과 콘텐츠 유형이 선택됨, When 검색, Then 두 조건과 키워드를 만족하는 결과만 표시.
- Given 전체 유형, When 검색, Then 관광지·숙박·음식점·문화시설·공연축제·여행코스·쇼핑 모두 조회 가능.
- Given 조회 중, When 새 검색이 시작됨, Then 이전 결과가 새 결과를 덮어쓰지 않음.
- Given 빈 결과 또는 실패, When 응답, Then 빈 결과와 오류를 구분하며 다시 검색 가능.
- 공공 API 키 없으면 고정 샘플 모드임을 화면에 명시. 실 API 검증 전 F101은 부분 완료.

## 회원 F107 F108

- 가입: 이메일을 trim·소문자 정규화, 이름 2~30자, 비밀번호 8~128자, 확인 일치. 중복 이메일 거절.
- 로그인: 올바른 자격증명만 세션 생성. 조회·수정·탈퇴는 현재 세션의 회원만 대상.
- 수정: 표시 이름만 변경. 탈퇴는 비밀번호 재확인 후 계정과 세션 제거.
- 로그아웃: 세션 제거. 새로고침은 탭 세션 유지.
- 비밀번호 찾기: 등록 시 발급한 복구 코드와 이메일, 새 비밀번호로 데모 재설정. 기존 비밀번호 반환 금지. 재설정 후 세션 종료.
- 로컬 저장소의 비밀번호·복구 코드는 salt와 PBKDF2로 해시하여 저장. 브라우저 데모는 실제 인증 경계가 아니며 실제 개인 계정 사용 금지.
- 저장소 손상·버전 불일치·쓰기 실패는 오류로 안내. 손상 데이터 자동 덮어쓰기 금지.

## 품질

추가 제안 RND-01~14: Three.js/cannon-es 공 던지기·3D 스핀·원근·착지 판정·전국 시도/시군구/읍면동 후보 저장, 관광공사 GW 미리보기·카카오 상세지도. [상세 수용 기준](features/random-trip.md). 경계는 KOSTAT2013이며 최신 경계로 주장하지 않는다.

360·768·1440px에서 주요 흐름 및 가로 넘침 확인. 필드 오류와 상태 메시지 접근성 제공. 외부 데이터는 textContent 또는 escaping으로 출력. 로그에 이메일·비밀번호·복구코드·API 키·검색 원문 기록 금지.

추가 제안 UIA-01~07: 사용자 시나리오 기반 화면 분리, 최대3단계 탐색, 후보/상세 독립화, 검색 상태 유지, 직접 주소/복귀, 요청 취소, 반응형·접근성. [상세 수용 기준](features/ui-navigation.md), [재배치 계획](../docs/ui-reorganization.md).
