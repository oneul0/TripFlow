# EnjoyTrip 디자인 시스템

주말 여행 페스티벌을 중심으로 대표 영역에는 사진·큰 제목·브랜드 퍼플을, 검색과 입력 영역에는 밝은 표면과 명확한 상태를 사용한다.

## 토큰과 컴포넌트

`src/tokens.css`는 브랜드·행동·강조·상태 색상, 타입 크기, 간격, 반경, 그림자와 모션 시간을 정의한다. `src/design-system.css`는 이를 사용하는 레이아웃과 컴포넌트다. 기존 style.css·editorial.css·party.css는 삭제해 덮어쓰기 계층을 없앴다.

- 브랜드: 퍼플. 주요 행동: 코랄. 강조: 노랑. 본문: 진한 중립색.
- 타입: 히어로 48~77px, 섹션 26~36px, 카드 22px, 본문 14px, 보조 12px.
- 간격: 4·8·12·16·24·32·48·64px 체계.
- 반경: 입력·버튼 10px, 카드·모달 18px, 히어로 26px.
- 버튼: 기본·hover·active·focus-visible·disabled. 입력: 기본·focus·disabled 및 네이티브 유효성 검사. 계정 안내: 성공·오류 상태.
- 카드: 동일 이미지 비율과 정보 순서, 가벼운 hover 반응. 제목과 본문은 사진 위에 겹치지 않는다.
- 1440px: 3열, 768px: 2열, 360px: 1열. 모바일 검색은 지역·유형 두 열과 전체 폭 키워드·버튼.

## 모션 규칙

hover 160ms, 일반 전환 260ms, 등장 480ms. 무한 회전과 움직이는 배경 효과는 제거했다. 첫 화면은 순차 등장하고 주요 섹션은 스크롤에 따라 한 번 나타난다.

일반 버튼 클릭은 파티클을 만들지 않는다. 회원가입 성공 시 UI가 `enjoytrip:success` 이벤트를 보내고 motion 모듈이 22개 파티클을 800ms 내 제거한다. 모달 안의 성공은 모달 레이어에 표시한다. 모션 줄이기 설정에서는 애니메이션·파티클을 끈다.

## 검증

단위·DOM 15개, Edge 사용자 흐름·반응형 4개와 빌드 검증. 정적 캡처로 데스크톱·모바일 레이아웃을 확인한다. 접근성 초점과 reduced motion 규칙은 포함했으며 정식 WCAG 인증이나 전체 스크린리더 검증을 의미하지 않는다.

## DS-02 전체 디자인 개선 계획 (2026-10-02)

따뜻한 중립 배경, 명확한 본문, 제한된 퍼플 강조로 전체 화면을 통일한다. 주요 행동은 퍼플, 오류/삭제는 빨강, 성공은 녹색으로 역할을 고정한다. 본문16px/보조14px, 버튼44px, 컨트롤10px/카드16px 반경, 공통 간격 토큰을 사용한다. 지도 지형 색은 콘텐츠 표현으로 유지한다.

주요·보조·삭제 행동의 위계를 정리하고 일반 카드의 그림자를 줄인다. 페이지 제목과 보조 안내는 압축한다. 내 여행은 계획/저장 코스/지역 후보를 같은 단계의 탭으로 구성한다. 기존 #candidates 직접 주소는 유지한다. 숨겨진 패널은 키보드 탐색에서 제외한다. 최대 깊이3, 기존 합성 데이터/실연동 제한을 보존한다.

수용 기준: Given 내 여행, When 탭 선택, Then 선택한 목록만 표시하고 현재 상태를 aria-pressed로 전달한다. Given 후보함 이전 주소, When 직접 진입, Then 지역 후보 탭으로 호환 이동한다. Given 360/768/1440px, When 주요 탐색/코스/랜덤 흐름 실행, Then 가로 넘침 없이 동작한다. 주요 버튼/본문/초점은 토큰을 공유한다.

근거: NN/g 시각 위계(https://www.nngroup.com/articles/principles-visual-design/), GOV.UK 공통 컴포넌트(https://design-system.service.gov.uk/components/), WCAG2.2(https://www.w3.org/TR/WCAG22/). 규칙 적용이 정식 접근성 인증을 의미하지 않는다.

DS-02 적용 결과: 공통 토큰의 본문16px/보조14px와 주요 행동색을 정리하고 코스·탐색·후보 화면의 중복 색상 일부를 토큰으로 교체했다. 내 여행은 계획/저장 코스/지역 후보 탭을 제공한다. #candidates는 기존 사용 흐름 보존을 위해 독립 주소와 메뉴를 유지하며 같은 후보함 DOM을 내 여행에서도 사용한다(자동 리다이렉트는 적용하지 않음). 지도 콘텐츠 색상과 기존 홈 이미지는 유지한다. 전체 CSS의 토큰 전환과 주 메뉴 축소는 아직 남아 있다.

검증: harness 정상 종료 — 단위·DOM73개, E2E23개, 빌드 통과. rules:check14개 통과. 내 여행 데스크톱·모바일 화면 시각 확인. 기존 번들 크기 경고와 실연동 제한 유지. 전체 WCAG 적합성 검증은 미실시.
