# 랜덤 여행 v2

## 조작

전국에서 시도를 고르고 시군구를 선택하면 읍면동까지 탐색한다. 지역 위를 확대하거나 클릭해서도 하위 지역으로 들어갈 수 있다. 공을 잡고 원형으로 움직여 스핀을 준 뒤 위로 쓸어 놓는다. 방향·세기·스핀 입력과 던지기 버튼으로도 같은 물리를 사용할 수 있다. 모션 감소 설정에서는 결과만 표시한다.

공 회전·원근 렌더링은 [Three.js](https://threejs.org/docs/), 강체의 이동·각속도·지면 충돌은 [cannon-es](https://pmndrs.github.io/cannon-es/docs/)를 사용한다. Rapier도 검토했으나 현재 단일 공·지면에는 WASM 초기화가 없는 cannon-es를 선택했다. 외부 CDN이 아닌 잠금 파일에 고정된 패키지를 번들한다. 직접 작성한 포물선 적분은 제거했고 커브 힘·입력 감도만 게임 규칙으로 유지한다. WebGL 미지원 환경에는 Three.js SVGRenderer를 사용한다.

후보의 **관광정보**를 누르면 선택 지역의 경계와 해당 시도 관광정보 최대20개가 나온다. 상세 행정동 내부 목록이라고 표시하지 않는다. 좌표가 유효하면 마커 선택과 카카오 길찾기로 연결된다. map/live 모드에서는 카카오 지도/스카이뷰·확대 컨트롤을 제공하며 SDK 실패 시 경계 미리보기와 목록을 유지한다.

## 실행 모드

- `npm run dev`: 외부 요청 없는 경계/합성 관광정보.
- `npm run dev:map`: 카카오 공개 JavaScript 설정만 사용하며 관광정보는 합성 샘플.
- `npm run dev:live`: 한국관광공사 GW와 카카오를 명시적으로 사용. 관광 키가 없으면 시작 오류.

공공데이터 출처: [한국관광공사_국문 관광정보 서비스_GW](https://www.data.go.kr/data/15101578/openapi.do). 기존 `KorService2/areaBasedList2` 어댑터에 첫 페이지 미리보기를 추가했다. 코드는 `areaCode`를 사용하며 KOSTAT 원본 코드를 그대로 보내지 않는다. 관광 키는 기존 허용 설정을 유지하며 환경값·요청 URL을 로그에 출력하지 않는다.

## 실제 연동 확인과 제한

자동 검증: 전체 하네스 정상 종료(단위·DOM56개, E2E13개, 빌드 통과), 규칙검사14개 통과. 360·768·1440px 주요 흐름과 샘플 화면을 확인했다. JS 초기 번들 약2.93MB/gzip691KB로 크기 경고가 있으며, 전국 경계와 렌더링 라이브러리가 포함된다. 규칙검사와 실제연동 검증은 별개다.

2026-10-02: 관광 키 미설정으로 실 GW 호출 미검증. 카카오 공개 키 설정 존재만 확인했으며, 별도 map 모드에서 SDK 로딩 실패를 확인했다. 공개 키·등록 도메인·서비스 설정의 추가 확인이 필요하다. 원문 오류·키·URL·실연동 캡처는 출력하지 않았다. 자동 검증의 SDK 대체 테스트 통과를 실연동 성공으로 간주하지 않는다.

전국 경계는 [KOSTAT 2013](third-party/korea-boundaries.md)이며 역사적 명칭을 유지한다. 최신 경계, 실제 모바일 터치 기기 감도, 계정/기기 간 후보 동기화는 미검증/미지원이다. 저장 형식은 이전 후보와 호환된다.
