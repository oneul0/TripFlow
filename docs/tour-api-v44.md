- `한국관광공사_개방데이터_활용신청방법_매뉴얼_v3.3.docx`: 신청 절차 참고용. 신청·키 발급·실연동 활성화는 수행하지 않았다.

## 반영

지역기반 조회와 후보 미리보기 모두 기존 areaCode 대신 lDongRegnCd를 전송한다. UI 및 저장된 코스의 내부 지역 식별자는 유지한다. 법정동 응답은 legalRegionCode/legalDistrictCode로 보존하며 기존 관광 sigunguCode에 넣지 않는다. 전국 17개 시도 변환에는 강원51·전북52를 포함한다.

분류 필터는 classification.large/middle/small을 받으며 API에는 lclsSystm1/2/3으로 전송한다. XLSX 제목의 lclsSystem 철자는 API 파라미터가 아니다. 상위 분류 누락, 존재하지 않는 조합, 관광타입 불일치는 호출 전에 거절한다. 캠핑 AC05는 관광타입28로 분류한다. 첨부 표에 여행코스25 분류행이 없으므로 임의 매핑하지 않는다. 분류 없는 유형25 조회는 유지한다.

NaN·범위 밖 좌표는 지도 좌표로 제공하지 않는다. 샘플 모드, 공개 환경변수 허용 목록과 화면 흐름은 그대로 유지한다.

## 한계 및 후속 검증

- 매뉴얼 도입부의 옛 areaCode2 예제보다 v4.4 개정 내역과 오퍼레이션 정의를 적용했다.
- 분류는 첨부 표의 스냅샷이며 실시간 코드 디렉터리 동기화는 구현하지 않았다.
- TOUR-45 후속 작업으로 탐색 화면의 접힌 ‘세부 분류’에 대·중·소분류를 연결했다. live 모드에서만 사용하며 샘플 모드는 미분류 안내를 제공한다. 상위 분류와 유형 변경 시 하위 선택을 초기화한다.
- KOSTAT2013 지도 경계를 현재 법정동 경계로 갱신한 작업은 아니다. 관광정보 미리보기는 시도 단위다.
- 실제 서비스 인증·CORS·쿼터·현재 운영 응답은 별도 live 점검이 필요하다. 합성 응답 테스트가 이를 보증하지 않는다.
- 법정동 코드의 관리 출처: https://www.code.go.kr/stdcode/regCodeL.do?menuNo=101010100010

검증: tests/tour-v44.test.js, tests/catalog.test.js, tests/tour-preview.test.js. 처음 추가한 회귀 테스트 두 건의 실패를 확인한 뒤 어댑터를 수정했다.

## TOUR-46 실연동 확인

서버 전용 TOUR_API_KEY로 같은 앱의 /api/tour GET 경로를 연결했다. 2026-10-02 실제 부산 미리보기 HTTP200, 20건, 전체2228건 응답을 확인했다. 키와 전체 API 응답은 기록하지 않았다. 개발 실행은 npm run dev:live이며 이번 실연동 확인 주소는 http://127.0.0.1:5176 이다. 기본5175 서버는 샘플을 유지한다. 운영 정적 호스팅은 별도 서버 경로가 필요하다.

브라우저 실조회: 부산 문화시설121건 표시 확인. 변환된 클라이언트 모듈에 실제 관광 키가 포함되지 않음을 값 출력 없이 확인했다. 카카오 SDK 연결은 실패하여 도메인/사용 설정 확인이 남았다. 규칙15개, 단위83개, E2E26개, 빌드 통과.

## TOUR-47 / MAP-20 전국 탐색 수정

기존 일괄 조회의1000건 제한으로 부산 등 대량 결과가 실패하는 문제를 페이지별20건 조회로 해결했다. 탐색 화면은 Catalog.page → Tour.findPage 경로를 사용하며 전체 건수와 현재 페이지를 표시한다. 검색어·구역별 지도 집계는 현재 페이지 기준이며 다음/이전 페이지로 탐색한다. 지역 변경 시 지도/시군구를 해당 지역의 KOSTAT2013 경계로 교체한다. 최신 행정경계 갱신은 별도다. 실 API 첫 페이지: 부산2228건·제주2118건·경기9432건 중 각각20건 HTTP200 확인.

## MAP-22 범위 기반 지도

지도는 locationBasedList2로 화면 범위를 조회하고 목록 페이지와 데이터를 분리했다. 위치 조회의 반경 상한20km에 맞춰 최대16개 원으로 분할하며 한 번에 최대40회 요청 후 부분 조회를 명시한다. 전체 완료인 경우에도 지도 시군구 집계는2013 경계 기준이다. 실제 서울 일부 범위에서 HTTP200,224건,partial=false 확인. 좌표·키·전체 응답은 저장하지 않았다.
