# TOUR-44: 제공 문서 대조 결과

## 근거

- `한국관광공사_개방데이터_활용매뉴얼(국문)_v4.4.docx`: 2026-02-10 개정 내역 및 지역기반 관광정보 조회 명세.
- `신분류체계정보 관광타입정보 연계 정의서.xlsx`: 유효 소분류 234행. 병합된 대·중분류를 상속하고 국문 관광타입을 사용해 `src/data/tour-classification.json`으로 정리했다.
- `한국관광공사_개방데이터_활용신청방법_매뉴얼_v3.3.docx`: 신청 절차 참고용. 신청·키 발급·실연동 활성화는 수행하지 않았다.

## 반영

지역기반 조회와 후보 미리보기 모두 기존 areaCode 대신 lDongRegnCd를 전송한다. UI 및 저장된 코스의 내부 지역 식별자는 유지한다. 법정동 응답은 legalRegionCode/legalDistrictCode로 보존하며 기존 관광 sigunguCode에 넣지 않는다. 전국 17개 시도 변환에는 강원51·전북52를 포함한다.

분류 필터는 classification.large/middle/small을 받으며 API에는 lclsSystm1/2/3으로 전송한다. XLSX 제목의 lclsSystem 철자는 API 파라미터가 아니다. 상위 분류 누락, 존재하지 않는 조합, 관광타입 불일치는 호출 전에 거절한다. 캠핑 AC05는 관광타입28로 분류한다. 첨부 표에 여행코스25 분류행이 없으므로 임의 매핑하지 않는다. 분류 없는 유형25 조회는 유지한다.

NaN·범위 밖 좌표는 지도 좌표로 제공하지 않는다. 샘플 모드, 공개 환경변수 허용 목록과 화면 흐름은 그대로 유지한다.

## 한계 및 후속 검증

- 매뉴얼 도입부의 옛 areaCode2 예제보다 v4.4 개정 내역과 오퍼레이션 정의를 적용했다.
- 분류는 첨부 표의 스냅샷이며 실시간 코드 디렉터리 동기화는 구현하지 않았다.
- TOUR-45 후속 작업으로 탐색 화면의 접힌 ‘세부 분류’에 대·중·소분류를 연결했다. live 모드에서만 사용하며 샘플 모드는 미분류 안내를 제공한다. 상위 분류와 유형 변경 시 하위 선택을 초기화한다.
- KOSTAT2013 지도 경계를 현재 법정동 경계로 갱신한 작업은 아니다. 관광정보 미리보기는 시도 단위다.
- 실제 서비스 인증·CORS·쿼터·현재 운영 응답은 별도 live 점검이 필요하다. 합성 응답 테스트가 이를 보증하지 않는다.
- 법정동 코드의 관리 출처: https://www.code.go.kr/stdcode/regCodeL.do?menuNo=101010100010
