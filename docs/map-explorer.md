# 서울 지도 탐색 v1

`npm run dev`는 외부 요청 없는 샘플 경계 지도다. `.env`의 `VITE_KAKAO_MAP_APP_KEY`에 공개 JavaScript 키를 설정하고 SDK 도메인 `http://127.0.0.1:5173`을 등록한 후 `npm run dev:map`으로 실행하면 실제 카카오 배경지도에서 합성 관광정보를 탐색한다. 이 모드는 TourAPI 키를 브라우저에 주입하지 않는다. `npm run dev:live`는 관광정보와 카카오 모두 연동하는 별도 모드다.

서울 구 경계 또는 구 버튼으로 선택하며 선택 윤곽선과 목록을 연결한다. 마커와 목록의 지도 버튼은 장소 상세 패널과 선택 강조를 연결한다. 지도 이동은 목록을 자동 변경하지 않고 범위 검색 버튼으로 현재 조회 결과를 좁힌다. 전국 서버 집계·최신 행정경계·일정·카카오 로그인은 이번 버전 범위가 아니다.

집계는 중복 제거한 현재 조회 결과만 사용한다. 좌표 없는 장소와 서울 밖의 장소는 목록에 유지하며 지도 미표시 개수를 안내한다. 구별 좌표 포함 판정은 경계 도형으로 계산한다. TourAPI sigunguCode는 문자열로 보존하지만 KOSTAT 코드와 같은 값이라고 가정하지 않는다. 초기 경계는 2013년 단순화 데이터이고 화면에 출처와 연도를 표시한다. 최신 경계 교체 시 같은 BoundaryCatalog 계약을 사용한다.

지도 SDK는 src/maps/kakao-map.js에 격리한다. 클러스터링은 확대 수준에 따라 개별 마커로 전환된다. 밀도 Canvas는 좌표를 화면 픽셀로 변환하고 구역 경계에 마스킹하며 합성 레이어의 불투명도를 48%로 제한한다. 확대 전환 중에는 숨기고 완료 후 재투영한다. SDK 오류 시 경계 미리보기와 목록을 유지하며 재시도를 제공한다.

## 검증

명세: specs/features/map-explorer.md. 자동 검증은 npm run harness로 수행한다. 2026-10-02 단위·DOM 30개, Edge E2E 5개와 샘플 빌드 통과. 실제 카카오 SDK에서 지도 표시·종로구 윤곽선·집계 9개와 목록 필터링, 지도 다각형 클릭에 따른 서대문구 선택, 경복궁 선택과 상세 패널 연동을 확인했다. 관광정보는 합성 샘플이며 실제 TourAPI 정확성을 증명하지 않는다. 실제 연동 화면에는 개인 계정이나 위치를 넣지 않는다.

지역 포함 판정과 집계는 이 환경의 Node 단일 측정에서 100개 6ms, 1,000개 14ms, 5,000개 57ms였다. 합성 좌표와 현재 서울 단순화 경계에 대한 로직 측정으로, 모바일이나 전체 SDK 렌더링 성능을 보장하지 않는다.
