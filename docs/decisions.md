- 실 API 키가 없어 F101은 부분 완료로 기록한다. 추가 기능은 필수 실연동 검증 전 진행하지 않는다.

## CB 블록 코스 (2026-10-02)

사용자가 서버를 제외한 구현을 요청했다. 기존 저장소와 공유 버전/복사 서비스를 재사용하고 후보 장바구니만 추가했다. 서버·신규 의존성은 추가하지 않았다. 코스 화면의 부가정보는 예상 시간·1인 소비 금액만 표시하며 이전 점수/리뷰 UI 계약은 CB 명세로 대체한다. 원본 데이터와 핵심 계산/리뷰 테스트는 유지한다.

자유형 그래프 대신 순서가 명확한 단일 연결 목록을 사용한다. 드래그는 브라우저 기본 기능을 사용하고 동일한 버튼 조작을 제공한다. 경로 API 없이 이동 시간을 임의 산출하지 않으며 사용자가 입력한 구간 추정치는 순서 변경으로 연결이 바뀌면 초기화한다. 후보 장바구니와 계획의 소유자는 기존 회원 ID 또는 익명 체험 사용자 ID를 따른다.
