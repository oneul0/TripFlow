# 설계 결정

- 2026-10-02 후속 요청: 직접 구현 대신 라이브러리 검색·적용을 요청하여 Three.js 0.186.1과 cannon-es 0.20.0을 고정했다. SVGRenderer도 검토·적용하되 실제 브라우저의 부드러운 구체 표현에는 WebGLRenderer를 사용하고 미지원 시 SVG로 대체한다. 전국 KOSTAT2013 3단계 경계로 서울 제한을 해제했다. 관광공사 GW는 관광정보용이며 경계는 별도 출처다. 카카오지도는 후보 관광정보의 경계·마커·지도 종류·확대 컨트롤에 사용한다. 실제 관광API 미검증·카카오 SDK 실패 상태는 숨기지 않는다.

- 2026-10-02: 사용자가 물리·스핀 기반 랜덤 여행 계획에 대해 "구현 시작해줘"로 요청한 범위에서 RND 개발을 진행한다. F101 실연동 미완료 제한은 유지한다. 확보된 서울 25개 구 2013 경계를 사용하며 전국·읍면동은 미제공이다. 사전 추첨 대신 실제 첫 착지점으로 판정하며 지역별 동일 확률은 보장하지 않는다.

- 사용자의 요구대로 모듈형 모놀리식으로 구현한다. 브라우저 단일 앱이며 후속 서버도 단일 배포 단위로 구성한다.
- 현재 요구된 확장 지점만 함수 계약과 명시적 생성자 주입으로 구성한다. DI 컨테이너·범용 플러그인 시스템·이벤트버스는 도입하지 않는다.
- 회원은 프론트 과제의 로컬 데모다. 비밀번호 원문 찾기는 구현하지 않고 가입 시 복구코드로 재설정한다.
- 검색은 공급자에서 지역·유형으로 조회한 후보의 제목·주소를 검색한다. 후속 검색 시스템은 Search 구현을 교체하고 같은 모놀리스 내 데이터 모듈에 접근한다.
- 중앙 로그·AI 제공자는 현재 미연결이다. Logger의 허용 필드만 sink에 넘기고 sink 실패는 기능에서 격리한다.
- 실 API 키가 없어 F101은 부분 완료로 기록한다. 추가 기능은 필수 실연동 검증 전 진행하지 않는다.
- 2026-10-02: 사용자가 지도 설계와 안전 하네스·필수 규칙 구성 후 "구현 진행해줘"로 지도 구현을 요청했다. 이 요청 범위에서 MAP 샘플 기반 개발을 진행한다. F101 및 실제 Kakao 연동 검증은 미완료 상태를 보존한다. 전국 집계는 이번 서울 탐색 구현과 분리한다.
- 서울 초기 경계는 southkorea/seoul-maps의 KOSTAT 2013 단순화 데이터(Apache 2.0)를 사용한다. 최신 경계가 아닌 개발 기준 데이터로 화면에 기준연도를 표시한다.
- TDD에서 미구현 스텁 대상으로 서비스 8개, API·UI 5개 실패를 확인한 후 구현해 통과시켰다. E2E의 모달 닫기 누락은 테스트 사용자 흐름을 수정해 통과시켰다.

- 2026-10-02: 사용자 요청에 따라 UIA-01~07 화면을 재배치한다. depth는 내부 탐색 계층이며 홈1→기능2→상세3으로 제한한다. 목록/지도는 동일 화면 전환, 계정은 전역 대화상자 내부 교체다. 기존 상태와 단일 배포를 유지하는 해시 탐색을 사용하고 라우터 의존성은 추가하지 않는다. F101 및 지도 실연동 제한은 유지한다.

- 2026-10-02 코스 설계 제안(미구현): 기존 F104/F110에 연결하고 비공개 계획/불변 공개 버전/저장 참조/리뷰/개인 적합도를 분리한다. 동일 모놀리스에서 공급자 포트로 확장하며 AI는 초안 제안만 한다. 숫자 정책과 보존기간은 제안으로 남기며 실 개인정보·실공유 도입은 서버 권한/삭제 검증 이후다. [설계 근거](course-recommendation-design.md).

- 2026-10-02 사용자의 구현 요청으로 단계1~2 당일 합성 코스 체험을 구현했다. 기존 로컬 회원과 체험 작성자를 분리하고 서버 인증 전 실공유를 주장하지 않는다. sample-fit-1의 구간·비용은 고정 합성 fixture이며 원래 CRS 운영 정책과 별도다. 순수 로직/DOM 실패 테스트와 첫 E2E 실패를 확인한 후 구현했다. 전체 운영 계약은 아직 미완료다.
